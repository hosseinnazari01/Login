# Login
# 🔐 سیستم ورود ساده با زبان پایتون

این پروژه یک سیستم ورود (Login System) ساده است که با استفاده از زبان برنامه‌نویسی Python طراحی و پیاده‌سازی شده است.

در این برنامه، نام کاربری و رمز عبور از پیش تعیین شده‌اند و اطلاعات واردشده توسط کاربر با مقادیر ذخیره‌شده مقایسه می‌شوند.

## 🚀 قابلیت‌های برنامه

- دریافت نام کاربری از کاربر
- دریافت رمز عبور از کاربر
- بررسی صحت نام کاربری و رمز عبور
- نمایش پیام موفقیت در صورت ورود اطلاعات صحیح
- نمایش پیام خطا در صورت ورود اطلاعات اشتباه

## 🛠️ مفاهیم استفاده‌شده

- متغیرها (Variables)
- دریافت ورودی با `input()`
- دستورات شرطی `if` و `else`
- عملگر مقایسه‌ای `==`
- عملگر منطقی `and`
- نمایش خروجی با `print()`

## ⚙️ نحوه عملکرد برنامه

ابتدا نام کاربری و رمز عبور معتبر در متغیرهای مشخص‌شده تعریف می‌شوند.

سپس برنامه نام کاربری و رمز عبور را از کاربر دریافت می‌کند و با استفاده از دستور شرطی `if` و عملگر منطقی `and`، هر دو مقدار را بررسی می‌کند.

اگر هر دو اطلاعات صحیح باشند، پیام موفقیت نمایش داده می‌شود؛ در غیر این صورت، پیام خطا به کاربر نمایش داده خواهد شد.

## 🎯 هدف از ساخت پروژه

هدف از این پروژه، تمرین متغیرها، دریافت ورودی، مقایسه اطلاعات و استفاده از دستورات شرطی و عملگرهای منطقی در زبان پایتون است.
